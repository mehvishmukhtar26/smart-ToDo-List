Smart To-Do List Application

About

A beginner-friendly task management web application developed using HTML, CSS, and JavaScript as part of the InternNova Week 5 JavaScript Project.

Features

- Add new tasks
- Mark tasks as completed and undo completion
- Edit existing tasks
- Delete tasks
- Filter tasks by All, Pending, and Completed
- Save tasks using browser localStorage
- Responsive user interface
- Input validation

Technologies Used

- HTML5
- CSS3
- JavaScript

How to Run

1. Download or clone this repository.
2. Open "index.html" in a web browser.
3. Add and manage your tasks.

Storage

Tasks are stored locally in the browser using localStorage.
