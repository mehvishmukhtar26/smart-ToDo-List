Task 1: Project Planning

Project Title

Smart To-Do List Application

Objective

To develop a simple, user-friendly web application that helps users organize and manage their daily tasks.

Technologies Used

- HTML for webpage structure
- CSS for styling and responsive design
- JavaScript for task management and interactivity
- localStorage for saving tasks in the browser

Main Features

- Add new tasks
- Edit and delete tasks
- Mark tasks as completed or undo completion
- Filter tasks by All, Pending, and Completed
- Save tasks automatically in the browser

Expected Outcome

A functional and responsive To-Do List application that allows users to manage their daily tasks efficiently.
